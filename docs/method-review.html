Method review n = 60 calls EN / HI / KN

Four methods, one broken candidate list

Fuzzy matching, dense retrieval, context matching and an LLM reranker were each tried on recovering a medicine name from noisy call-centre audio. Only one of them was ever the problem — and it wasn't the one that got replaced. This is what each contributed, what each cost, and where the pipeline had to be diverted.

Per method

What each one gave, and what it took away

28.3%Fuzzy

Fuzzy string matching

The right tool, configured in a way that destroyed it. Drug names are arbitrary proper nouns — lexical matching is exactly the correct instinct, and after repair this remains the backbone of the whole system.

  • GaveThe only approach that ever beat noise. Carries all three languages after repair.
  • Tookfuzz.WRatio falls back to partial ratio when two strings differ in length, so the three-letter filler ham scored 90 against astHAMon-L Tablet. Filler outranked real names in every single result list.
  • TookN-grams capped at 4 words, but cleaned catalogue names run to 6 (chemiclo sp 100mg 325mg 10mg tablet). The full name was literally unformable.
  • Took2 796 s per sample — 46 hours for one full run. Nothing could be measured, so nothing could be fixed.

3.3%Dense

Dense retrieval

The weakest performer by a wide margin — five times worse than even the broken fuzzy matcher. The model is not malfunctioning; it is answering a different question correctly. Embeddings encode topic, and a brand name carries no topic.

  • GaveA multilingual encoder, in principle able to bridge Devanagari and Latin without transliteration.
  • TookIn practice it bridged nothing: Hindi and Kannada stayed at 0%.
  • TookIt ranked by symptom similarity, actively pulling results away from the drug named in the call.
  • TookTop-5 equals Top-1 at 3.3% — when it is wrong, the answer is absent from the list entirely, so no reranker can recover it.

n/aContext

Context-based matching

Only the embedding-generation half was ever scripted; ranking and evaluation stayed in the notebook, so this never produced a number to compare. That absence is itself the finding — it consumed effort without generating evidence.

  • TookIts context_text is composition plus description — text that never contains the drug name. It can only match on what a drug does.
  • TookThat is the same symptom axis dense retrieval already failed on, with the one discriminative field removed. Its failure was predictable from the dense-retrieval result.
  • GaveA genuinely useful signal, aimed at the wrong stage: composition is strong evidence for disambiguating two candidates, not for retrieving them. It belongs in the reranker.
+1.7LLM Δ

LLM reranking

The most misread component. On broken candidates it looked like the strongest idea in the system, lifting dense retrieval from 3.3% to 11.7%. It was in fact working near its ceiling and papering over the real defect.

  • Gave+8.4 points over dense retrieval alone — the largest single gain of the original pipeline.
  • TookThat gain was an illusion of headroom. The candidate list contained the right answer 13.3% of the time and the LLM converted 11.7% — it was already extracting 88% of everything it was handed. It was never the bottleneck.
  • GaveOn repaired candidates it doubles Kannada, 10.5% → 21.1%, where lexical evidence is weakest.
  • TookIt hurts English, 54.2% → 50.0%, second-guessing lexical matches that were already correct. Net across all 60: fixed 3, broke 2.

Implication

Applied globally the LLM is worth +1.7 points. Applied only to romanized transcripts — where its help is real and its harm is not — it should be worth appreciably more. It is a repair tool for weak evidence, not a general-purpose ranker.

Process flow

Where the pipeline had to be diverted

The original flow had no stage between speech-to-text and matching. Two-thirds of the data arrived in Devanagari or Kannada script and was compared, character by character, against a Latin-only catalogue — an operation that cannot succeed at any threshold.

The five diversions that mattered

  • ScriptRomanize Indic script before matching. Devanagari फेनोक्सो → phenokso, comparable to catalogue Fenexo for the first time.
  • ScorerReplace WRatio with ratio and drop sub-4-character candidates, removing the partial-match inflation that poisoned every list.
  • ViewsScore each candidate twice — literally, and on a Metaphone key. phenokso 120 taibaleta and fenexo 120 tablet both reduce to FNKS 120 TBLT.
  • CombineMerge the two views based on source script: English spelling is trustworthy so phonetics only rescue it; romanized text has no reliable spelling, so agreement across both views decides. A single global weight measurably could not serve both.
  • MeasureSplit ground truth only on a space-padded slash. Lancas D 10mg/30mg Capsule is one dosage, not two answers — 15% of the set had been unscoreable regardless of prediction.

The binding constraint is transcription, not matching

transcribe.py:76 truncates every recording to 30 seconds via ffmpeg -t 30, and in these calls the medicine is normally named at the end. Sample S020 cuts off mid-sentence at “yeah i think taking”; S012 never names a drug at all, only “your antacid capsule”.

No matcher can recover a name that was never transcribed. For Hindi and Kannada this cap — not the algorithm — is what holds the numbers down, and lifting it is worth more than any further tuning.

Next

Where the remaining points are

  1. Remove the 30-second truncation and re-transcribe. The single highest-value change, and the only one that raises the Hindi and Kannada ceilings rather than chasing them.
  2. Apply the LLM reranker only to romanized transcripts. It reliably helps where lexical evidence is weak and reliably hurts where it is strong; gating it captures the gain without the English regression.
  3. Close the English ranking gap. 54.2% against a ~96% ceiling is the largest pool of recoverable samples in the set, and it needs no new data.
  4. Move composition and description into the reranker. Useful for choosing between candidates, actively harmful for producing them — which is where it was being used.
  5. Hold out a validation split before tuning further. The current combination weights were fitted on the same 60 samples they are scored against.
